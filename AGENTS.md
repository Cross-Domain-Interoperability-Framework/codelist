# AGENTS.md - AI Agent Guidance for CDIF Codelist

## Project context

This repository hosts the CDIF Codelist profile for representing controlled vocabularies and classification schemes as SKOS ConceptSchemes in JSON-LD.

## Key constraints

1. **Bidirectional hierarchy** — if `skos:narrower` is present, child concepts must also have `skos:broader`. Both directions are required. Enforced by JSON Schema (`allOf` with `required`) and SHACL (SPARQL-targeted shape).

2. **CDIF core metadata** — `schema:identifier`, `schema:dateModified`, and `schema:license` or `schema:conditionsOfAccess` are required on ConceptScheme. These take precedence over dcterms equivalents.

3. **Array convention exception** — unlike other CDIF profiles, repeatable SKOS properties do NOT require array serialization for single values. Both `"skos:prefLabel": "Material"` and `"skos:prefLabel": [{"@value": "Material", "@language": "en"}]` are valid.

4. **Required on every concept** — `@id` (resolvable URI), `skos:prefLabel`, `skos:inScheme`, `skos:definition`.
